# isrpo

Учебный репозиторий к практической работе № 6–7 по ИСРПО.

## Что отрабатывается

- создание и клонирование репозитория GitHub;
- подготовка файлов командой `git add`;
- фиксация изменений командой `git commit`;
- отправка коммитов на GitHub командой `git push`;
- получение изменений командой `git pull`;
- получение сведений об удалённых изменениях без их слияния командой `git fetch`.

## Практический файл

`Hello.txt` был добавлен в клоне `third`; коммит отправлен в `origin`.

## Основной цикл

```bash
git status
git add Hello.txt
git commit -m "Добавлен Hello.txt"
git push
git pull
```

При работе с двумя клонами одного репозитория изменения сначала фиксируются локально. Если удалённая ветка уже содержит новый коммит, нужно получить его через `git pull`; при изменении одной и той же строки может потребоваться разрешить конфликт.
